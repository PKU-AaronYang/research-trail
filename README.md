# Research Trail v4.0 · 做当前这一步

一个纯静态科研导航网页。选项目，复制当前科学任务，实际完成后查看下一步。网页负责流程，模型负责当前科研工作；无需账号、API 或构建工具。

## 部署与更新

解压 `research-trail-v4-github.zip`，把内部文件上传到 GitHub Pages 发布目录。详细覆盖、删除旧文件及刷新步骤见 [DEPLOY.md](DEPLOY.md)。现有网址继续使用原发布位置即可。

## 日常使用

每次打开先到项目首页。新建项目可以选择入口；每个项目的进度、笔记和改写独立保存。项目页默认只显示当前步骤；重命名、浏览阶段、笔记、中文翻译和备份收在“更多”。

- **Chat → Chat / Codex → Codex**：继续同一研究的对话或工作区，直接复制本步任务。
- **Chat → Codex**：网页给出一次交接请求，发到当前 Chat。将生成的 `FINAL CODEX EXECUTION PROMPT` 直接发到 Codex 执行。
- **Codex → Chat**：请求生成包含 `NEXT CHAT TASK` 的交接，整份一次发到 Chat 即开始目标任务。无需第二份 Prompt。
- 交接后点击“已将生成内容发到…”，目标页会提示无需重复复制。网页不能实际读取模型对话或替你验证是否完成。

每个任务末尾给简短 Stage Result。只有真实完成或已明确处理问题，才按网页分支继续。跨平台确需的图表/稿件仍需让目标平台实际取得；本地路径本身不是文件传输。

英文任务在“更多”中有中文阅读对照；这不是在线翻译服务，不自动翻译个人改写。

## 本地数据、备份与删除

数据只保存在**当前浏览器、当前网址**的 localStorage，不上传 GitHub，也不跨设备同步。

- 首页“更多 → 备份与恢复”可导出全部 JSON；项目内也可单独导出。
- 导入先预览，再确认新增项目。重名加后缀，不覆盖现有项目；支持旧版单项目和多项目备份。
- 项目卡“删除”或项目内“更多 → 删除此项目”，确认后仅删除当前浏览器中的该项目。取消不做修改；已导出的备份、其他浏览器和 GitHub 文件不受影响。
- 同一原网址更新，旧版记录自动迁移。笔记和个人资料保留；旧执行文本移入“更多 → 完成情况与个人记录 → 查看升级前个人记录”，不会自动执行旧规则。
- 清理网站数据或换浏览器/网址会失去原访问位置的记录，操作前请导出。保存失败或多标签页冲突时会提示，请先备份再刷新。

可以直接把后续规则调整发给维护者，并提供当前源码或仓库地址。新版规则与旧个人记录分别保留。

变更概要见 [CHANGELOG.md](CHANGELOG.md)。
